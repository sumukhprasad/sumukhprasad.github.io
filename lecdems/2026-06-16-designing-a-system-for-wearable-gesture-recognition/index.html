--- layout: lecdem title: "Talk: Designing a System for Wearable Gesture Recognition" ---


It is often assumed that computer interfaces are purely driven by surface-based input methods. This talk & demo explored how a gesture-based input device might be constructed economically, and what uses it may have.

This talk grew out of an IoT coursework project, which the professor asked to rework into a proper talk. While the presentation covers the same work, it was adapted and expanded for a lecture-demonstration format.
